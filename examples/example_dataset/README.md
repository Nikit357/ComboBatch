# Example dataset

Five public GEO cohorts, subset from a larger harmonization benchmark. Generated by
`scripts/build_example_dataset.py`; see `PROVENANCE.md` for accessions, attribution and
the two judgement calls the build makes.

| File | Contents |
|---|---|
| `example_exp.tsv.gz` | Expression, **samples × genes**, 144 × 21,890, 13.8 MB gzipped. |
| `example_ann.csv` | Annotation for the same 144 samples, 12 columns. |
| `PROVENANCE.md` | Accessions, platforms, counts, the exact filter used, and per-series attribution. |

| Accession | n | Platform | Preservation | Diagnoses |
|---|---|---|---|---|
| GSE64555 | 40 | GPL570 microarray | FFPE | DLBCL |
| GSE148070 | 40 | GPL17586 microarray | FF | FL |
| GSE119234 | 20 | RNA-seq | FF | normal B (memory, GC, naive) |
| GSE69033 | 30 | GPL20188 microarray | FF | normal B (5 subsets) |
| GSE62241 | 14 | RNA-seq | FF | FL |

Three properties are deliberate:

- **Four platforms, both FF and FFPE, and malignant plus normal biology** — enough to
  exercise cross-platform harmonization and biology preservation at once.
- **Ragged gene coverage.** GSE69033 and GSE119234 measure an identical 6,925-gene
  subspace; the other three cover ~15,880 each. Only **6,797 genes are present in all
  five**, 5,877 are entirely absent, and 41.7% of the matrix is NA. `strict` keeps 6,797
  of 21,890 genes, which is the honest cost of refusing to impute.

  **Set `max_na_frac` above 0.35 or the imputation axis does nothing here.** Because the
  missingness is platform-driven, it is *banded*: a gene is measured by a whole cohort or
  by none of it, so the per-gene NA fraction takes only five values — 0.0 (6,797 genes),
  0.347 (9,080, missed by the GSE69033 + GSE119234 pair), 0.625 (8), 0.653 (128, measured
  *only* by that pair) and 1.0 (5,877). `max_na_frac` matters only where it crosses a
  band, and **the default 0.20 falls below every one of them** — so at defaults `knn`,
  `softimpute` and `missforest` keep exactly the zero-NA genes `strict` keeps, have
  nothing left to fill, and return an identical matrix. At 0.4 they keep 15,877 genes and
  the four strategies genuinely diverge. `examples/configs/full_crossproduct.yaml` sets
  it accordingly; `PROVENANCE.md` tabulates the bands.
- **Raw, not log-transformed.** `20_shambhala` requires raw input and log-transforms
  internally. The maximum value is ~40,000.

```bash
combobatch run --config examples/configs/minimal.yaml       # ~12 s, no R needed
```
